# Secure Login System

This is a cybersecurity mini-project developed using Python Flask.

## Features

- User registration
- Secure login
- Password hashing using bcrypt
- Input validation
- SQL injection protection using parameterized queries
- Session management
- Logout feature
- Demo two-factor authentication using OTP

## Technologies Used

- Python
- Flask
- SQLite
- bcrypt
- HTML
- CSS
